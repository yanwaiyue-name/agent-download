这个包自带离线安装包（在「安装包」文件夹里），也支持联网补下。
使用方法：
  1. 不确定电脑架构时，先双击「双击检测.bat」
  2. 双击「双击启动.bat」，按编号下载或启动安装
  3. 同一软件有多种格式时，按提示选一种（回车 = 默认格式）
  4. 自动下载失败时，可从本文件的“官网”或“当前直链”手动下载

Agent 管理与工作台

  CC Switch
    适合：同时使用 Claude Code、Codex、OpenCode 等多个 Agent 的开发者
    用途：图形化管理多个 Agent 的安装、更新、Provider、MCP、Skills 和配置。
    格式：MSI 安装包 + 免安装 zip，x64 与 ARM64 都有。

  Open Cowork
    适合：希望通过图形界面使用 AI Agent、文件处理和 MCP 的普通用户
    用途：图形化 AI Agent 工作台，支持 Skills、MCP、文件处理和多模型。
    格式：Windows 安装版（x64）；ARM64 Windows 会用系统模拟运行。

  RunJam
    适合：同时使用 Claude Code、Codex 和 Gemini 的编程用户
    用途：一个窗口管理 Agent、项目、会话、编辑器和终端，并支持一键安装 Agent。
    格式：Windows 安装版（x64）；另有 macOS 的 arm64 / x64 dmg。

  Desktop CC GUI
    适合：想在一个图形界面运行多个 AI 编程引擎的开发者
    用途：统一使用 Claude Code、Codex、OpenCode、DeepSeek Harness 等 Agent。
    格式：Windows 安装版（x64）；另有 macOS 的 arm64 / x64 dmg。

  Watt Toolkit（瓦特工具箱，原名 Steam++）
    适合：需要 Steam 社区/商店加速、GitHub 加速、本地令牌等工具的用户
    用途：开源网络加速与实用工具集，Steam 社区打不开、GitHub 拉不动时很好用。

    注意：免安装版是 .7z，解压需要 7-Zip；不想装 7-Zip 就用安装版。

【格式怎么选】

  安装版    双击装到系统里，装完开始菜单有图标。绝大多数人选这个。
  MSI       系统级安装包，适合公司电脑批量部署 / 域环境推送。
  免安装    单个 exe，双击就能用，不写注册表，拷到 U 盘就能带走。
  压缩包    解压后双击里面的 exe，不用安装（zip 直接右键解压；7z 需要装 7-Zip）。
  商店版    微软商店引导器，双击后要联网拉完整应用（目前只有 ChatGPT 这样）。

  同一软件选哪种都能用，功能一样，差别只在“装进系统”还是“绿色免安装”。

【按 Windows 架构选择】

  Intel / AMD 普通电脑：选择 x64
  骁龙 / 麒麟等 Windows ARM 电脑：优先选 ARM64；没有 ARM64 的软件可使用 x64 模拟运行
  32 位 Windows（x86）：本清单中的桌面软件均无适配版本

【下载后】

启动器下载的文件会放在「下载」文件夹，可以重复安装或留作备份。
如果这个包里带有「安装包」文件夹，里面的文件已经是放好的，
启动器会优先使用本地文件，显示「已就绪」后点一下就能装，不用联网。
「安装包\<软件名>\mac\」里的 dmg 是给 Mac 用的，Windows 上用不到。

请从以上官网或官方 Release 页面确认软件来源。Windows 对未签名安装包可能显示提示；
请先核对下载页面、文件名和发布者，再决定是否继续安装。
