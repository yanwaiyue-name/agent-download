========================================
  AI 桌面下载中心 · 使用说明
========================================

这是一个 Windows AI 软件安装中心，带完整离线安装包。
它会根据电脑架构自动选择合适的版本；同一个软件有多种格式时，会让你选装哪一种。


【最简单的用法：图形界面】

  双击「打开资源中心.bat」

  浏览器会自动打开一个软件目录页面，里面有：
    · 每款软件的卡片、图标、简介、大小和「已就位」标记
    · 左侧按分类筛选：桌面端 / Agents / IDE / CLI Code / 运行环境 / 开发环境
    · 顶部搜索框，输入软件名、厂商或关键词就能找到
    · x64 / ARM64 切换，自动对应到正确架构的安装包
    · 点「下载」直接保存，浏览器自带进度条，支持暂停和续传

  点卡片可以看详情：全部格式、macOS 版本、官方页面、安装注意事项。
  左侧底部的「使用说明」和「官方下载地址」也能在页面里直接查看。

  这个页面由你电脑上的一个小程序提供，只在 127.0.0.1 本地运行，
  不联网、不上传任何数据、不需要管理员权限。
  用完后，把标题为「AI 桌面下载中心」的窗口关掉就结束了。

  重复双击不会开出多个，会自动切到已经打开的那个页面。


【命令行方式（不想开浏览器时）】

  双击「双击启动.bat」，在黑色窗口里输序号安装。
  下面【建议先检测电脑】往后的说明都按这种方式写。


【建议先检测电脑】

  不确定电脑是 Intel/AMD 还是 ARM 芯片时，先双击「双击检测.bat」。

  检测结果会告诉你：
    · 电脑是 x64、ARM64 还是 32 位 x86
    · 每个软件适合下载哪个版本、默认是哪种格式
    · 哪些软件需要 x64 模拟运行
    · 内存和硬盘空间是否够用

  检测完成后会生成「本机检测报告.txt」。需要别人协助时，可以把这份报告发出去。

【下载和安装】

  1. 双击「双击启动.bat」
  2. 列表分为八类：
  桌面端：聊天、办公、多模型客户端（含 Hermes Agent、Watt Toolkit）
  Agents：Agent 工作台与管理器（CC Switch、Open Cowork、Goose、OpenHands、Cline、Grox 等）
  IDE：Cursor、Trae（国际版）、Trae CN（国内版）、Windsurf、VS Code
  CLI Code：Claude Code、Gemini CLI、Qwen Code、Kimi CLI、Pi、Codex CLI、OpenClaw、Aider、iFlow CLI
  本地运行：Ollama、LM Studio（在自己电脑上跑开源模型）
  实用工具：Motrix（多线程下载器）、图吧工具箱（硬件检测）
  运行环境：WebView2、VC++ 运行库（桌面软件缺库打不开时装）
  开发环境：Python、Node.js、Git、7-Zip、uv、PowerShell 7、Windows Terminal（要用命令行工具才装）
  3. 输入软件前面的序号，按回车
  4. 如果这个软件有多种格式，会列出来让你选：
       安装版    双击装到系统里，装完开始菜单有图标（推荐）
       MSI       系统级安装包，适合公司电脑统一部署
       免安装    单个 exe，双击就能用，不写注册表，拷走就能带走
       压缩包    解压后双击里面的 exe，不用安装
       .7z 包    也是压缩包，但 Windows 自带功能解不开，需要装 7-Zip
                 没装 7-Zip 时启动器会提示，这时直接改用同软件的安装版最省事
       商店版    微软商店引导器，双击后要联网拉完整应用（ChatGPT 属于这种）
      npm 安装  官方没发安装包，用命令行装（如 npm install -g @openai/codex）
      pip 安装  同上，Python 包（如 pip install aider-chat）
      官网下载  只有官网页面，需要自己进去选版本和架构
     直接回车 = 用默认格式（一般就是安装版 / MSI）
  5. 软件显示「已就绪」时，说明本地已有安装包，会直接问你要不要现在装
  6. 软件显示「需下载」时，会先下载到「下载」文件夹，再问你要不要装
  7. 输入 A 会下载所有可下载软件的默认格式。文件较多、体积较大，建议按需要逐个选。
  8. 输入 V 会按「校验清单.txt」核对本地安装包是否完好。
     从网盘、QQ 传过来的大文件偶尔会被截断，装到一半才报错；

  注意：部分工具的状态显示「npm 安装」或「pip 安装」，表示官方没有提供
  安装包，必须用命令行装（例如 npm install -g @openai/codex）。
  「官网下载」表示该软件只有官网下载，没有直链，需要点开官网自己选版本。
     先校验一遍能提前发现，不用等装失败。
  9. 输入 Q 退出。

【推荐什么软件】

  打开同目录的「软件推荐与官方下载地址.txt」。里面有：
    · 每个软件适合什么人
    · 每个软件有哪几种格式、各有什么差别
    · 官方下载页和当前直链
    · x64 / ARM64 选择说明

  自动下载失败时，可以从该文件打开对应官网或官方 Release 页面手动下载。

【架构说明】

  x64    Intel / AMD 普通电脑，绝大多数电脑属于这一类
  ARM64  骁龙、麒麟等 Windows ARM 电脑，优先下载 ARM64 原生版
  x64*   当前没有 ARM64 原生版，Windows 会用 x64 模拟运行，速度可能较慢
  x64?   架构检测失败后暂按 x64 推荐，安装前请人工确认系统位数
  x86    32 位旧系统，本清单中的桌面软件都无法安装

【运行环境（桌面软件依赖）】

  这一项最容易被忽略：软件装上了，双击却打不开、窗口一片白，
  通常不是软件本身的问题，而是缺了底层的运行库。

  「运行环境」分组里放了三个：

    WebView2 运行时（在线版）   1.8 MB，安装时要联网
    WebView2 运行时（离线包）   204.9 MB，安装时不用联网
    VC++ 运行库 2015-2022       24.4 MB

  什么时候需要装：
    · 启动器打开时顶部会提示「本机缺少 xxx」，那就装
    · 或者双击「双击检测.bat」，报告里【运行环境】那几行标黄的就是缺的
    · 没有提示就不用装，Windows 11 基本都自带

  WebView2 两个版本装一个就行：电脑能上网用 1.8 MB 的在线版，
  不能上网才用 204.9 MB 的离线包。

【开发环境（要用命令行工具才装）】

  「开发环境」分组里是 Python、Node.js、Git、7-Zip，一共 8 个安装包
  （每个都有 x64 和 ARM64 两个版本，启动器会按你电脑自动选）。

  先说清楚：上面那些桌面软件不需要它们，都是自带运行时的，
  双击就能用。只有下面这几种情况才要装：

    要装 Claude Code、opencode CLI 这类命令行工具  ->  装 Node.js
    要跑 .py 脚本、用 pip 装包                      ->  装 Python
    要克隆 GitHub 仓库、用 git 命令                  ->  装 Git
    要解压 .7z 文件（比如 Watt Toolkit 免安装版）     ->  装 7-Zip

  怎么装：
    1. 双击「双击启动.bat」
    2. 找到「开发环境」分组，输入对应序号
    3. 按提示下一步，装完会问你还要不要装别的

  装完怎么验证（新开一个命令行窗口，敲）：

    python --version     能显示 Python 3.13.10 就对了
    node -v              能显示 v24.22.1 就对了
    git --version        能显示 git version 2.56.0 就对了

  三个都提示「不是内部或外部命令」，说明装的时候没加进 PATH：
    · Python 最容易踩这个坑 —— 安装界面最下面有个
      「Add python.exe to PATH」的勾，必须勾上，默认是不勾的
    · Node.js 的 MSI 会自动加，但装完要重开窗口才生效
    · Git 安装时「Adjusting your PATH」保持默认的中间选项就行

  想用别的版本：Python 除了 3.13.10 还有 3.14.2，
  链接在「软件推荐与官方下载地址.txt」里，自行下载安装即可。

【四个要注意的地方】

  1. ChatGPT / Codex
     Windows 下载的是微软商店引导器（0.8 MB），不是完整离线包。
     启动后仍需要联网从商店下载完整 ChatGPT 应用。

  2. Hermes Agent
     Hermes 有官方桌面版（Windows / macOS 都提供），不再只是命令行。
     本包里的 Hermes-Setup.exe 是官方引导器，首次启动会联网拉运行时。
     如果你习惯命令行，也可以自己用 PowerShell 装 CLI。

  3. ARM64 电脑
     CC Switch、OpenCode、Cherry Studio 有 ARM64 原生版（含免安装格式）。
     其他只提供 x64 的软件可以模拟运行，但速度和续航可能较差。

  4. macOS 用户
     安装包\<软件名>\mac\ 里有 dmg，那是给 Mac 用的。
     Windows 启动器不会读它们，Mac 用户直接拷走双击即可。

【本地安装包和下载缓存】

  启动器下载的文件会保存到「下载」文件夹，下次可以直接复用。
  如果这个包里带有「安装包」文件夹，里面的安装程序已经放好了，
  启动器会优先使用本地文件，显示「已就绪」后点一下直接安装，全程不联网。

  「校验清单.txt」记录了每个安装包的 SHA256。怀疑文件不完整时，
  在启动器里输入 V 就能逐个核对，损坏的会明确列出来。
  没有这个文件（联网下载版）也不影响正常使用。

【首次安装提示】

  Windows 可能对未签名安装包显示提示。请先确认文件来自
  「软件推荐与官方下载地址.txt」中的官方页面或官方 Release，
  再核对文件名和发布者后继续安装。

【遇到问题】

  · 下载失败：打开「软件推荐与官方下载地址.txt」，从对应官网或官方 Release 页面手动下载
  · 下载卡住：按 Ctrl+C 中断，重新打开启动器后再选一次
  · 想要另一种格式：选同一个软件时换一个格式序号即可
  · 想看下载记录：打开同目录的「日志.txt」
  · 双击没有打开：确认解压完整后，再双击「双击启动.bat」
