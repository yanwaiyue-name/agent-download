# 安全说明

## 这个项目做什么，不做什么

**做**：整理官方下载地址、检测本机架构、从官方源下载安装包、校验文件完整性。

**不做**：不破解、不修改安装包、不夹带任何附加内容、不上传任何数据。

## 本地服务的安全边界

`资源中心服务.ps1` 是一个本地 HTTP 服务：

| 项 | 实现 |
|---|---|
| 监听地址 | 仅 `127.0.0.1`，不监听 `0.0.0.0` |
| 外网访问 | 不可能，未被外部接口暴露 |
| 数据上传 | 无。所有请求都在本机处理 |
| 管理员权限 | 不需要。用 `TcpListener` 而非 `HttpListener`，普通账户可绑定端口 |
| 端口 | 自动选择空闲端口，不占用固定端口 |
| 路由 | 只有 `/`、`/api/apps`、`/dl`、`/doc` 四条 |
| 目录穿越 | 下载路径限制在 `安装包/` 和 `下载/` 之内 |

## 安装包来源

本仓库**不托管任何安装包**。所有二进制都来自各厂商官方渠道。

安装前请自行核对：
1. 文件名与官方页面是否一致
2. 数字签名发布者是否为该厂商（未签名的应用会触发 SmartScreen，属正常）
3. 文件大小是否与官方公布的一致

仓库里的 `校验清单.txt`（发布包内）提供 SHA256，可用 `launcher.ps1 -Verify` 逐个核对。

## 需要代理的部分

以下官方源在中国大陆直连不稳，这是网络现实，不是项目问题：

- `downloads.claude.ai`
- `hermes-assets.nousresearch.com`
- `github.com` 的 Releases 下载

工具内置了 GitHub 加速站回退，其余需自行准备网络条件。
