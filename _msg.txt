feat(4.4.0): 下载后强制校验官方 SHA256，加速站改为可选

把「官方链接」升级成「可验证的下载」。

核心改动：
- sources.json 每个安装包可带 sha256 字段
- launcher.ps1 下载后立即比对：不一致就删文件换源重试，不再只打印哈希
- launcher.ps1 -NoMirror：只用 GitHub 官方直链，不碰第三方加速站
- 走加速站时明确打印「第三方加速站，下载后会校验官方哈希」
- scripts/update-hashes.ps1：刷新哈希，优先取上游官方清单
- verify.ps1 新增 [5.7/6] sha256 fields，格式错直接 fail
- scripts/test-hash-verify.ps1：自测拦截逻辑真的会删文件

已固定 24/93：
- 15 条来自上游官方校验清单（dsh SHA256SUMS.txt、uv sha256.sum、
  claude-code SHASUMS256.txt、qwen-code / pi / grox SHA256SUMS）
- 9 条自行下载计算（codex / 7zip / hermes / webview2 / terminal / ccgui）

剩余 69 条暂未固定。原因很实际：当前网络下 GitHub 只有 80KB/s 左右，
93 个包合计约 6GB，全量下载不现实。没固定哈希的条目不会被拦截，
只显示算出来的值 —— 这一点在 SECURITY.md 和 README 里都写清楚了，
不假装全覆盖。补全方法：pwsh ./scripts/update-hashes.ps1 -Proxy <你的代理>
